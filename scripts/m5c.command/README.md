## 一、功能

比较两个文件的 MD5，判断字节内容是否一致。

该脚本适合 `.command` 双击运行，也可以在终端中执行。启动后的说明展示、依赖检查和核心流程都写在脚本内部。

## 二、运行

```zsh
./m5c.command
```

如果已经自行加入 PATH，也可以执行：

```zsh
m5c
m5c [参数...]
```

## 三、交互规则

MD5 适合日常文件一致性校验；安全签名用途应改用 SHA-256。
